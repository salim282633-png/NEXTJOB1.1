# NEXT JOB — Yemen-focused SEO Publisher

هذا المحرك مخصص حصريًا لنشر مقالات عن **وظائف اليمنيين داخل السعودية**. لا يستخدم بيانات Seed ولا يصف أي أرقام تقديرية بأنها Live.

## التشغيل الإنتاجي

الـWorkflow: `.github/workflows/seo-publisher.yml`

- يعمل مرة يوميًا الساعة 06:15 بتوقيت السعودية.
- ينشر مقالًا واحدًا كحد أقصى في كل تشغيل.
- يمكن تشغيله يدويًا من GitHub Actions مع كلمة مستهدفة اختيارية.
- الكلمة اليدوية تُرفض إذا لم تذكر بوضوح اليمنيين + العمل/الوظائف + السعودية أو مدينة سعودية.

## المفتاح المطلوب

في GitHub:

`Settings → Secrets and variables → Actions → New repository secret`

الاسم:

`GEMINI_API_KEY`

استخدم مفتاح Gemini مخصصًا لهذا المحرك وقيّده قدر الإمكان من Google Cloud. لا تضع المفتاح داخل المستودع أو ملفات Vite.

> ملاحظة: هذا المفتاح منفصل عن `VITE_GEMINI_API_KEY` المستخدم اختياريًا في واجهة المتصفح لمولد رسائل التقديم.

## مسار النشر

1. يختار كلمة من `seo/yemeni-keywords.json` لم يسبق تغطيتها.
2. يطلب من Gemini مقالًا عربيًا أصليًا مخصصًا لليمنيين في السعودية.
3. يطبّق بوابات جودة ونطاق وتكرار.
4. إذا نجح، ينشئ صفحة مستقلة في `public/guide/<slug>/index.html`.
5. يحفظ نسخة المصدر في `seo/published/<slug>.json`.
6. يحدّث `public/guide/articles.json` وصفحة `/guide/` و`sitemap.xml`.
7. يلتزم GitHub Action بالتغييرات إلى `main`، فيلتقطها Render تلقائيًا.

## بوابات الجودة

يرفض المحرك المقال إذا:

- لم يذكر اليمنيين بوضوح.
- لم يكن متعلقًا بوظائف داخل السعودية.
- كان قريبًا جدًا من مقال منشور.
- كان أقل من الحد الأدنى للمحتوى أو بلا أقسام/FAQ كافية.
- احتوى ادعاء ترخيص أو ضمان توظيف/راتب/نقل خدمات.
- احتوى رقم هاتف أو بيانات اتصال تبدو شخصية.
- حاول اختلاق عدد وظائف حية أو تحويل المقال إلى إعلان شاغر مزيف.

## فحص يدوي

```bash
npm run seo:check
```

تشغيل يدوي محلي (يتطلب Secret/Environment متاحًا محليًا):

```bash
GEMINI_API_KEY=... npm run seo:publish
```
